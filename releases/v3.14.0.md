# v3.14.0 Release Notes

**Release Date**: 2026-03-16

## Highlights

This release addresses critical integration issues and adds significant improvements to skill orchestration and autonomous memory management.

## New Features

### OpenClaw Memory Bridge
- New `MemoryBridge` class for bidirectional memory sync
- Supports `syncTo()` and `syncFrom()` operations
- New MCP tool: `nexus_openclaw_memory_sync`
- Storage location: `~/.antigravity/nexus-prime/`

### Autonomous Memory Management
- Configurable `MemoryConfig` interface:
  - `decayRate` (default: 0.05)
  - `priorityRetention` (default: 0.95)
  - `flushEntropyThreshold` (default: 0.9)
- New `maintenanceCycle()` method for entropy-based expiration
- Access-frequency retention: frequently accessed memories decay slower

### Fuzzy Skill Matching
- `resolveSkillSelectors()` now uses Jaccard similarity
- Keyword overlap scoring between goal and skill name/instructions
- Relevance threshold: 0.3+ for fuzzy matches
- Returns top 5 matches sorted by relevance

### Adaptive Token Optimization
- Thresholds adapt based on file count:
  - >20 files: skip threshold 0.25, outline threshold 0.45
  - <5 files: skip threshold 0.10, outline threshold 0.30
  - Default: skip 0.15, outline 0.40
- Enhanced `scoreRelevance()` with path component matching

### Agent Auto-Configuration
- Workspace-level configs now write during npm install
- Added idempotency guard (skip if file modified <60s ago)
- Per-client error handling (one failure doesn't block others)

### Pattern Promotion
- `AgentLearner.promoteRepeatingPatterns()` method
- Queries memories tagged #agent-learning with accessCount >= 3
- Creates runtime skills from repeating patterns
- Tags sources with #promoted-to-skill

### Ollama Embeddings
- Set `NEXUS_EMBED_MODE=ollama` to use Ollama for embeddings
- Default model: `nomic-embed-text` (768-dim vectors)
- Configurable via `NEXUS_OLLAMA_ENDPOINT` and `NEXUS_OLLAMA_MODEL`
- Fallback chain: Ollama → OpenAI API → Local TF-IDF

### HuggingFace Embeddings
- Set `NEXUS_EMBED_MODE=huggingface` to use HuggingFace Inference API
- Default model: `sentence-transformers/all-MiniLM-L6-v2` (384-dim vectors)
- Configure via `NEXUS_HF_API_KEY` and `NEXUS_HF_MODEL`
- Fallback chain: Ollama → HuggingFace → OpenAI → Local TF-IDF

### KV-Bridge Ollama Inference
- KVBridge now supports Ollama as inference backend
- Use `inferenceBackend: 'ollama'` in KVBridge config
- Implements `/api/generate` endpoint for merge decision inference

### New Agent Adapters
- **Aider**: config at `~/.aider/mcp.json`, instruction at `.aider/nexus-prime.md`
- **Continue.dev**: config at `~/.continue/config.json`, instruction at `.continue/nexus-prime.md`
- **Cline**: config at `~/.vscode/cline-mcp.json`, instruction at `.cline/nexus-prime.md`
- Run `nexus-prime setup <client>` to auto-configure

### Docker Support
- Added `Dockerfile` for containerized deployment
- Added `docker-compose.yml` with optional Ollama companion
- `docker compose up` runs just Nexus Prime
- `docker compose --profile with-ollama up` adds local Ollama
