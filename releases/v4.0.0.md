# Nexus Prime v4.0.0

`v4.0.0` hardens the engine core for long-running, local-first coding sessions. Memory persistence, graph mirroring, orchestration shutdown, compaction cleanup, specialist loading, and public release surfaces now move together as one release instead of drifting across separate subsystems.

## Highlights

- Memory startup now applies WAL/NORMAL/cache/foreign-key/temp-store pragmas before schema work and uses targeted recall queries instead of full-table hot-path scans.
- TF-IDF vocabulary state is now persistent through `vocabulary_stats` and `vocabulary_meta`, so recall weighting rebuilds from cumulative `doc_count` instead of only the latest document batch.
- Orchestrator disposal is synchronous, compaction sentinel cleanup is explicit, and CLI/runtime entrypoints own shutdown behavior.
- Specialist planning/listing stays synchronous while heavy specialist details are lazy-loaded from split payload files to reduce cold-start cost.
- New regression tests lock in SQL safety, entropy bounds, graph-failure signaling, compaction cleanup, skill/Darwin memory sinks, and orchestrator lifecycle semantics.

## Shipped Changes

- Added typed events for:
  - `memory.flushed`
  - `memory.health.tick`
  - `graph.sync.failed`
  - `graph.coverage.low`
  - `orchestrator.disposed`
  - `nexus.shutdown`
  - `ledger.duplicate-prevented`
  - `nexus.circuit-open`
  - `nexus.circuit-tripped`
  - `darwin.cycle.complete`
- Centralized canonical secret detection in `security-shield.ts` and reused it from memory checks.
- Parameterized memory access-count updates and clamped cooldown entropy to the `[0,1]` range.
- Added `recallCandidateLimit`-backed hot-path recall selection and debounced vault flushes with `flushVaultSync()` on dispose.
- Replaced timeline ancestry walking with a recursive CTE.
- Added orchestration dedupe and circuit-breaker state management.
- Mirrored skill outcomes into hippocampus memory and Darwin applied/rejected cycles into cortex memory.
- Split the giant specialist roster into a lightweight generated metadata index plus on-demand detail payload files.
