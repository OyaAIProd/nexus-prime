# v4.6.0 — Context Ascension

**Always-On Compression, Native Search & Operator Telemetry**

## Highlights

### Always-On Token Optimization
Bootstrap now auto-applies token optimization whenever candidate files are known. Bootstrap and orchestrate responses also surface token and USD savings directly, so the optimization result is visible in the normal operator flow instead of hidden in a diagnostic-only path.

### Project-Scoped Session Summaries
Session close and `nexus_session_dna` now persist reusable project summaries. The next bootstrap can recover that summary before broad file reads, giving returning sessions a cheaper continuity path.

### Dynamic Context Discovery
The MCP tool list now keeps core lifecycle tools expanded while summarizing non-core tools by default. Full contracts can be pulled on demand through `nexus_describe_tool`, reducing tool-description token spend on first contact.

### Native Search and Skill Bridge
`nexus_search` exposes sparse n-gram retrieval and search statistics directly on the MCP surface. Installed gstack workflows can also appear as Nexus-native capabilities through the optional bridge layer.

### Opt-In Telemetry and Dashboard Signals
Remote telemetry remains off by default, uses anonymized install IDs, and now honors consent boundaries by refusing to queue pre-consent events. The dashboard banner now surfaces savings, search-query activity, and telemetry status in one place.
