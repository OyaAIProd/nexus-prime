# Nexus Prime v4.1.0

`v4.1.0` hardens the control plane around the operator-facing path that matters most: dashboard truth, engineering-first routing, explicit Synapse/Architects coordination, and release-safe verification of the full bootstrap flow. This release keeps the public MCP names and dashboard endpoints stable while making the internals more reliable under real multi-agent execution.

## Highlights

- Dashboard hot endpoints now use bounded caching, stream-aware refresh suppression, in-flight request dedupe, and targeted rerendering instead of broad refresh fan-out.
- Broad technical audits of dashboard/UI/frontend/backend/API/control-plane behavior now route to engineering execution with preserved secondary frontend/review signals instead of getting trapped in blocked PM/data/marketing lanes.
- Synapse now boots with an explicit Architects coordination bridge, and correlation IDs flow through missions, sorties, field reports, dashboard entities, and POD telemetry.
- New integration and regression tests cover mandate → worklist → sortie → convergence, dashboard stream refresh behavior, canonical runtime catalog refresh, and engineering-lane routing for CTO-style audits.

## Shipped Changes

- Added a typed coordination bridge between Synapse and Architects at Nexus Prime startup instead of post-start provider mutation.
- Added correlated `worklistId`, `workItemId`, `strikeTeamId`, and `correlationId` flow across event-bus payloads and POD telemetry.
- Reworked dashboard refresh behavior so health, feature-registry, and repo-tree reads are cached and routine updates only rerender affected surfaces.
- Disabled dashboard-local seeding as the primary catalog path; the dashboard now reports canonical runtime mode and refreshes from the real runtime registries.
- Tightened intent classification so control-plane audits stay on engineering routes while pure build prompts remain classified as feature work.
- Added integration coverage for matching Architects work-item completion through the normal Synapse sortie path.
- Fixed the dashboard health collector catch block so the release lint gate stays green.
